# NilPerit

> *Omnia mutantur, nihil interit.* — Everything changes, nothing perishes. (Ovid)

NilPerit is a personal backup system. It pulls your data from cloud services and local sources into encrypted, versioned storage that you control. When something happens in the cloud, your data is still here.

## Status

**Pre-alpha. Nothing works yet.** The storage format is not stable and will change without notice. Do not use NilPerit for real data.
